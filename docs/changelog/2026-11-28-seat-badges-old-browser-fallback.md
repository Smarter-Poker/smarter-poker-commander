# Table seat badges keep their sizes on browsers without container queries

Date: 2026-11-28 (Central)
Scope: Club Commander table views (Tables, Table Tablets, dealer tablet,
Waitlist Desk Seat Player picker, TV table board)

## Why

#178 sized every seat badge as `clamp(min, Ncqw, px)` inside a
`container-type: inline-size` seat box, with an `@container (max-width: 520px)`
compact phone layout. Safari before 16 and Chrome before 105 have neither
container units nor container queries: they drop every declaration that names
`cqw` and skip the whole `@container` block. On such a browser (older venue
iPads and Android tablets) avatars collapsed to their 13px text size, names ran
unstyled, and on a phone-sized table up to 16 seat pairs overlapped (measured,
below).

## What changed

`src/components/commander/shared/ClubArenaTable.jsx` only; the five views are
untouched.

- `seatScale(ref)` writes the share of the box as
  `calc(N * var(--ca-u, 1cqw))` instead of `Ncqw`. A modern browser never has
  `--ca-u`, so it uses `1cqw` and computes exactly the size it did before. An
  old browser keeps the declaration (a `var()` is checked only when used).
- `ClubArenaTableFelt` (already rendered inside every seat box) runs a layout
  effect only where `CSS.supports('width: 1cqw')` and
  `CSS.supports('container-type: inline-size')` are not both true: it finds its
  seat box, measures it with a ResizeObserver (window resize/orientation
  listeners where ResizeObserver is missing too) and writes `--ca-u` = 1% of
  the box width in px, and `data-ca-compact` when the box is 520px or narrower.
  Where `aspect-ratio` is also missing (Safari < 15) it gives the square box its
  height.
- The compact rules are written once (`SEAT_COMPACT_RULES`) and emitted twice:
  inside the unchanged `@container` block, and as a twin generated by
  `compactFallbackCss()` with every rule scoped to
  `.ca-seat-box[data-ca-compact]` and every `Ncqw` rewritten to
  `calc(N * var(--ca-u))`. The twin is inert in a modern browser because the
  attribute is never set there.

## Tests

- `tests/unit/clubArenaSeatFallback.law.test.js` (new): seatScale values
  resolve to the same size through cqw and through the measured unit at 330 to
  1400px boxes, and contain no `cqw` outside the `var()` fallback; the compact
  layout exists in both forms and the twin has no `cqw` and every selector is
  scoped; feature detection is true only without container units (and when
  `CSS.supports` is missing or throws); the fallback writes 1% of the box, the
  compact switch, and the height only without aspect-ratio.
- `tests/unit/clubArenaTableSkin.law.test.js`: the seatScale assertion follows
  the new `var(--ca-u, 1cqw)` form.

## Render proof (no container queries)

Method: current Chrome cannot switch container queries off (no Blink flag
exists any more), so the run emulates an old engine in a Playwright context
(`/home/claude/perf-evidence/tools/shots-nocq.cjs`, NOCQ=1):
1. `CSS.supports()` answers false for any query naming cq units,
   `container-type` or `@container`;
2. `element.style` is handed out behind a Proxy (and `setProperty` wrapped)
   that drops any value naming a container unit outside a `var()`, which is
   exactly what an old parser does to React's inline styles;
3. `*{container-type:normal!important}`, so no size container exists and no
   `@container` rule can match.
An audit also counts any inline `style` attribute that still carries a raw
container unit (0 in every run). Same mocked data and overlap audit as #178's
`shots.cjs` (seat-badge pair overlaps and clipping per seat box), five views at
1280, 393 and 375.

| Build | Emulation | Seat overlaps + clips (15 view/width runs) | Avatar at 375 |
|---|---|---|---|
| main (#178) | no container queries | 1280: 14, 393: 53, 375: 55 (122 total) | 13px |
| this change | no container queries | 0 | 22-25px |
| this change | modern Chrome | 0 | 22-25px |

Every avatar size under emulation equals the modern size at all 15 runs (0
differences), and modern sizes equal #178's: the modern path is unchanged.
The Waitlist Desk open-seat click still posts `/api/commander/waitlist/seat`.
